# EF88 Firing Cycle

Interactive 3D animation of the EF88 Austeyr rifle's firing cycle, built with three.js. Rotate the rifle, make the body see-through, and step through the cycle to watch the bolt, carrier, gas piston, hammer, magazine and cartridge move.

**Live page:** https://atpinto.github.io/ef88-firing-cycle/

The outer body is generated from a photograph of an EF88; the internal parts are a simplified teaching model with approximate shapes and timing.
